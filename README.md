# Base Gas Tracker 🟦

Real-time gas prices for Base network - built for builders and operators.

**Live:** https://forge-builder.github.io/base-gas-tracker/

## Features

- 📊 Real-time gas from Base RPC
- 💡 Smart recommendations with savings estimates
- 🔔 Gas alerts (browser notifications when gas drops below target)
- ⏱️ Auto-refresh every 30 seconds
- 🎨 Builder-focused UI

## Why Base Builders Use It

- Optimize transaction timing for cost-sensitive operations
- Set gas alerts and get notified when fees drop
- See potential savings vs high-gas periods

## Tech

- Single HTML file (inline CSS/JS)
- Base RPC: `https://mainnet.base.org`
- CoinGecko API for ETH price

## Run Locally

```bash
# Just open index.html in a browser
# Or serve locally:
npx serve .
```
